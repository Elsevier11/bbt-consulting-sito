Priorità 24–72 ore

Ruotare. Chiudere. Autenticare.

SEC-01Critica

Segreti nel sorgente

Credenziali SQL, script di build e valori sensibili inclusi nelle configurazioni.

SEC-02Critica

Token legacy riproducibili

Chiavi statiche e formato proprietario permettono la costruzione di token validi.

SEC-03Critica

Allegati non protetti

Download legacy per GUID senza controllo evidente di autenticazione e ownership.

SEC-04Alta

Rimozione upload

Metodo di cancellazione privo dell’attributo di autorizzazione usato dal salvataggio.

SEC-05Alta

Bypass con debugger

L’External API seleziona un account fisso senza validare token quando trova il debugger.

SEC-06Alta

SignalR anonimo

Un client anonimo può tentare di trasmettere notifiche a tutti i collegati.

SEC-07Alta

Stored XSS

Dati applicativi vengono concatenati e assegnati direttamente a innerHTML.

SEC-08Alta

Dati sensibili nei log

Token non validi e request serializzate possono essere registrati integralmente.

SEC-09Alta

.NET 6 fuori supporto

L’External API usa un runtime che non riceve più aggiornamenti di sicurezza.

SEC-10Media

Deserializzazione rischiosa

Newtonsoft usa TypeNameHandling.All sui file di stato locali.

SEC-11Media

Plugin senza verifica

Le DLL PERS sono caricate automaticamente senza firma o hash visibili.

SEC-12Media

Swagger e HTTPS

Swagger è sempre disponibile e l’app non impone direttamente HTTPS.

SEC-13Media

Upload in memoria

I file vengono caricati interamente in RAM e manca una validazione completa del contenuto.

SEC-14Media

Processi da database

Lo scheduler avvia eseguibili e argomenti configurati nei job.

SEC-15Bassa

Chiave Firebase client

La chiave incorporata richiede verifica delle restrizioni in Google/Firebase.
